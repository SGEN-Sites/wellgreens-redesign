# Wellgreens: website redesign preview

A redesign preview of [www.wellgreens.store](https://www.wellgreens.store/), the website of Wellgreens (cannabis dispensaries in San Diego
County, California), prepared by SGEN Sites. **This is a pitch preview, not the live site.** Every page is marked
`noindex, nofollow`.

**Preview:** https://sgen-sites.github.io/wellgreens-redesign/

- 848 pages (467 in English, 381 in Spanish under `/es/`) at the live site's own paths.
- Shop, menu and store links open the live Wellgreens store pages.
- The Wellgreens name, marks, photography and copy belong to Wellgreens.
